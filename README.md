# OSORI Backend Portfolio

## 프로젝트 소개

OSORI는 사용자의 소비 내역을 기록하고 관리할 수 있는 가계부 서비스입니다.

수입, 지출 등록 및 반복적으로 발생하는 고정 지출을 관리할 수 있으며

소비 챌린지 기능을 통해 소비 습관 개선을 돕는 서비스입니다. 

본 프로젝트는 팀 프로젝트로 진행되었으며

저는 Backend 영역에서 사용자 도메인과 고정 지출 도메인을 담당했습니다. 

## 담당 역할 

### 사용자 계정 및 인증 기능
- 회원 가입 및 로그인 기능 구현
- 소셜 로그인 기능 구현
- JWT 기반 인증 처리
- 로그인 실패 횟수 기반 계정 잠금 기능 구현
- 휴면 계정 처리 기능 구현
- 회원 정보 수정

### 소비 관리 기능
- 고정 지출 등록 / 수정 / 삭제 기능 구현
- 고정 지출 데이터 조회 및 관리 로직 구현
- MyBatis 기반 데이터 접근 로직 작성
- Oracle DB 연동 및 SQL 작성

## 시스템 아키텍처  

Client(React) -> Spring Boot Server -> Oracle Database 

- React : 사용자 인터페이스
- Spring Boot : 인증 및 비즈니스 로직 처리
- Oracle DB : 사용자 / 지출 데이터 저장
- JWT : 로그인 이후 사용자 인증 처리

## 주요 기능 

### 로그인 및 사용자 인증

사용자의 아이디와 비밀번호를 검증하여 로그인 인증을 수행하고
인증 성공 시 JWT 토큰을 발급하도록 구현했습니다. 

- BCrypt 기반 비밀번호 암호화
- 로그인 성공 시 JWT 토큰 발급
- 계정 잠금 여부 확인 후 로그인 허용 여부 판단
- 로그인 성공 시 마지막 로그인 시점 업데이트
- 회원 상태(Y: 정상, H: 휴면, N: 탈퇴)에 따른 로그인 분기 처리

단순히 아이디와 비밀번호 일치 여부만 확인하는 것이 아니라
계정 상태 및 잠금 여부를 함께 확인하여 로그인 가능 여부를 판단하도록 구성했습니다.

### 로그인 실패 기반 계정 잠금

무차별 로그인 시도를 방지하기 위해 로그인 실패 횟수 기반 계정 잠금 정책을 구현했습니다.

- 로그인 실패 시 실패 횟수 누적
- 로그인 실패 5회 누적 시 계정 잠금
- 잠금 시간 10분 설정
- 잠금 상태에서는 비밀번호가 맞아도 로그인 차단
- 잠금 시간이 지나면 자동 해제
- 잠금 해제 시 로그인 실패 횟수 초기화

이를 통해 단순히 로그인 성공 여부만 확인하는 것이 아니라
사용자 계정 상태와 보안을 함께 고려하는 로그인 로직을 구현했습니다. 

### 소셜 로그인

사용자의 로그인 편의성을 높이기 위해 소셜 로그인 기능을 구현했습니다.

- OAuth 인증을 통해 사용자 정보 수신
- 최초 소셜 로그인 시 회원가입 절차 진행
- 일반 계정과 이메일이 중복되는 경우 계정 충돌 방지를 위해 연동 제한

이를 통해 사용자 계정 정보의 정합성을 유지하면서
일반 로그인과 소셜 로그인을 함께 지원할 수 있도록 구성했습니다.

### 휴면 계정 처리

장기간 로그인 하지 않은 계정을 구분하여 관리할 수 있도록 휴면 계정 처리 기능을 구현했습니다.

- 마지막 로그인 시점을 기준으로 휴면 계정 여부 판별
- 휴면 상태 계정 로그인 시 별도 안내 메시지 제공
- 프로필 설정 페이지에서 휴면 해제 후 서비스 이용 가능하도록 처리
- 회원 상태값을 기반으로 로그인 이후 접근 가능한 서비스 제한

장기 미사용 계정을 일반 계정과 구분하여 관리하고, 사용자 상태에 맞는 로그인 흐름을 제공할 수 있도록 했습니다.

### 고정 지출 관리

매달 반복적으로 발생하는 지출을 효율적으로 관리할 수 있도록 고정 지출 관리 기능을 구현했습니다.

- 고정 지출 등록 / 조회 / 수정 / 삭제
- 사용자별 고정 지출 데이터 관리

월세, 통신비, 구독 서비스와 같이 반복적으로 발생하는 지출을
별도로 관리할 수 있도록 하여 사용자의 지출 관리 편의성을 높였습니다.
